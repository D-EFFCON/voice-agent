# Marketing — voice-server

**Positioning statement:** For no-coders and low-coders who know their way around APIs but cannot stand up a WebSocket server, voice-server is the free voice agent server template that goes from GitHub to Railway in minutes, plugs into Twilio's voice products on the input side, and into any LLM and any automation tool on the output side, all through environment variables.

**ICP (detailed):** No-coders and low-coders comfortable with APIs, webhooks and automation tools such as Make, Zapier and n8n. They reach the template through the owner's YouTube audience. Segments beyond that: (not set).

**Pains & desired outcomes:**
- Pain: they want a voice agent answering a phone number, but hosted platforms charge per minute and hide the plumbing, sample repos are single-provider demos, and hiring a developer is out of reach.
- Desired outcome: a working voice agent on their own Railway account in under 30 minutes, using their choice of LLM and the automation tool they already use, that they own outright.

**Offers:** voice-server template. Free, MIT licensed, public GitHub repo.

**Proof points:** (not set). Nothing shipped yet.

**Competitors & alternatives:**
- Status quo: hiring a developer, or abandoning the idea.
- Hosted platforms: Vapi, Retell, Bland. Per-minute pricing, plumbing hidden, no ownership.
- Free alternatives: Twilio's own sample repos (single-provider demos rather than something you deploy and keep); Dograh (self-hosted but Python with Docker Compose, heavy for this audience); LiveKit Agents (needs a LiveKit server or Cloud plus SIP setup).
